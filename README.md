# 필라테스 센터 홈페이지 스킬

필라테스·요가·PT 센터 원장님이 Claude와 대화하면서 우리 센터 홈페이지를 처음부터 완성하는 스킬입니다.

시작하면 첫 질문에서 두 가지 중 하나를 고릅니다.

| | A. 결제형 | B. 홍보형 |
|---|---|---|
| 이런 분께 | 온라인 PT 같은 상품을 홈페이지에서 팔고 싶은 원장님 | 센터를 알리고 체험·상담 신청을 받고 싶은 원장님 |
| 예시 | 온라인 PT 4주 180,000원 결제 + 구매자 전용 운동 영상 | 센터 소개, 수업·가격, 시간표, 체험 신청서 |
| 결제 | 토스페이먼츠 (실결제는 사업자등록·토스 심사 후) | 없음 |
| 예상 시간 | 하루 | 2~3시간 |

두 갈래 모두 디자인, AI 상담 챗봇, GitHub 백업, Vercel 배포, 가비아 도메인 연결까지 포함합니다.

또 두 갈래 모두 **AEO**가 기본으로 들어갑니다. ChatGPT, 구글 AI 요약, 네이버 등에 "우리 동네 필라테스 추천해줘"라고 물었을 때 우리 센터가 나오도록, 홈페이지를 센터 정보의 정답지로 만들고(자주 묻는 질문, AI용 구조화 데이터, llms.txt) 검색 등록과 네이버·구글·카카오 정보 맞추기까지 안내합니다.
처음이라면 **B로 먼저 만들고**, 다음에 결제 기능을 추가하는 순서를 추천합니다.

## 설치 방법

Claude Code에 이 저장소 주소를 붙여넣고 이렇게 보내세요.

```
이 링크의 pilates-homepage-kr 스킬을 글로벌 스킬로 사용할 수 있도록 설정해줘.
(저장소 주소)
```

직접 설치하려면 `pilates-homepage-kr` 폴더를 `~/.claude/skills/` 안에 복사하면 됩니다.

## 시작 프롬프트 (복붙용)

계획 모드를 켜고 아래를 보내세요.

```
우리 필라테스 센터 홈페이지를 만들어줘.
사용자가 직접 해야 하는 설정은 플레이라이트로 네가 진행해줘. 로그인은 내가 할게.
마지막으로 네가 내 의도를 제대로 이해했는지 설명해줘.
```

연습이라면 질문에 "그냥 따라할게요"라고 답하면 예시 센터(바른숨 필라테스)로 진행됩니다.

## 주의
- 이 스킬이 만드는 약관·환불·개인정보 문서는 출발점일 뿐입니다. 실제 판매 전에는 원장님 상황에 맞게 고치고 필요하면 전문가 검토를 받으세요.
- 홈페이지 문구에 "치료", "교정 보장" 같은 의료 효과 표현은 쓰지 않도록 되어 있습니다.
