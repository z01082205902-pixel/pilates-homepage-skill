# 디자인

## 톤 3가지 (사용자가 하나 고름)

### 1. 웜 베이지 (기본 추천)
편안하고 따뜻한 동네 센터 느낌.
- 배경 `#F7F2EB`, 글자 `#2B2620`, 포인트 `#B5704D`(테라코타), 보조 `#8A9A7B`(세이지)
- 제목: Gowun Batang 또는 Noto Serif KR / 본문: Pretendard
- 둥근 모서리 16px, 사진은 자연광 느낌

### 2. 클린 화이트
깔끔하고 전문적인 느낌. 재활·체형 관리 강조에 어울림.
- 배경 `#FFFFFF`, 글자 `#111827`, 포인트 `#2F6F6A`(딥 그린), 구분선 `#E5E7EB`
- 제목·본문 모두 Pretendard (굵기 차이로 위계)
- 여백을 넉넉히, 사진은 밝고 선명하게

### 3. 다크 프리미엄
고급 1:1 프라이빗 센터 느낌. 온라인 PT 판매 페이지에 잘 어울림.
- 배경 `#121212`, 카드 `#1C1C1C`, 글자 `#F2EFEA`, 포인트 `#C9A96E`(샴페인 골드)
- 제목: Noto Serif KR / 본문: Pretendard
- 사진은 어둡고 대비 강하게

## 피할 것 (AI가 만든 티 나는 디자인)
- 보라·파랑 그라데이션 배경
- 모든 섹션이 똑같은 "아이콘 3개 카드" 반복
- 의미 없는 이모지 장식
- 운동과 상관없는 추상 일러스트

## 한국어 줄바꿈
- 전체에 `word-break: keep-all` (Tailwind: `break-keep`) 적용
- 큰 제목은 의미 단위로 직접 줄을 나눈다. 예: "하루 20분,<br/>집에서 바르게"
- 모바일 375px에서 단어가 중간에 잘리지 않는지 캡처로 확인

## 꼭 지킬 것
- 버튼 글자와 배경의 대비가 충분할 것 (흐릿한 회색 글자 금지)
- 이미지는 `next/image` 사용
- 움직임 효과는 은은하게, `prefers-reduced-motion` 존중
