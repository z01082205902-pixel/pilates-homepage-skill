# 페이지 구성

## 공통 원칙
- 모바일에서 먼저 보기 좋게 (원장님 고객 대부분이 인스타·카톡 링크로 휴대폰에서 들어온다)
- 화면마다 **눈에 띄는 버튼은 하나** (A: 결제하기 / B: 체험 신청하기)
- 휴대폰 화면 아래쪽에 그 버튼을 고정해 둔다 (sticky CTA)
- 이미지가 없으면 임시 이미지를 쓰고, 나중에 바꿀 위치를 `public/images/README.txt`에 적어둔다

---

- 두 갈래 모두 메인에 **자주 묻는 질문 12개**와 **한 줄 정의** 문장을 넣는다 (`aeo.md` 2장). 아래 섹션 목록의 "자주 묻는 질문"이 그 자리다.
- 모든 센터 정보는 `lib/center-info.ts`에서 가져온다. 화면에 숫자나 주소를 직접 적지 않는다.

## B. 홍보형

| 주소 | 페이지 | 섹션 |
|---|---|---|
| `/` | 메인 | 첫 화면(센터 한 줄 소개 + 체험 신청 버튼) → 이런 분께 맞아요 → 원장·강사 소개 → 수업 종류와 가격 → 시간표 → 회원 후기 → 센터 사진 → 오시는 길(네이버 지도 링크 또는 임베드) → 자주 묻는 질문 → 신청 버튼 |
| `/apply` | 체험 신청 | 신청서(이름, 연락처, 희망 요일·시간, 운동 목적, 개인정보 수집 동의 체크) |
| `/apply/done` | 신청 완료 | "연락드릴게요" 안내 + 카톡 채널 버튼 |
| `/privacy` | 개인정보처리방침 | `legal-pages.md` |

- 신청서는 Supabase `inquiries` 테이블에 저장된다 (`database.md`).
- 원장님은 Supabase 대시보드의 **Table Editor**에서 신청 목록을 본다. 관리자 페이지는 만들지 않는다 (초보자 부담 줄이기).
- 지도: 한국에서는 구글 지도보다 **네이버 지도 / 카카오맵**. 처음엔 "네이버 지도에서 보기" 링크 버튼이 가장 쉽다.

## A. 결제형 (온라인 PT)

| 주소 | 페이지 | 내용 |
|---|---|---|
| `/` | 메인 | 첫 화면(온라인 PT 한 줄 소개 + 가격 + 결제 버튼) → 이런 고민 있으세요? → 4주 동안 이렇게 진행돼요(주차별 흐름) → 받는 것 목록 → 원장님 소개 → 무료 맛보기 영상 → 후기 → 가격 카드 → 자주 묻는 질문 → 결제 버튼 |
| `/programs/[slug]` | 상품 상세 | 상품 설명, 주차별 커리큘럼, 추천·비추천 대상, 환불 규정 요약, 결제 버튼 |
| `/checkout/[slug]` | 결제 | 로그인 확인 → 주문 요약 → 토스 결제위젯 → 약관 동의 → 결제하기 |
| `/checkout/success` | 결제 성공 | 서버에서 결제 승인 → "내 프로그램으로 가기" |
| `/checkout/fail` | 결제 실패 | 이유 안내 + 다시 시도 |
| `/login` | 로그인 | 구글 로그인 버튼 |
| `/my` | 내 프로그램 | 결제 완료한 프로그램, 주차별 영상(유튜브 임베드)과 과제, 카톡 피드백 안내 |
| `/admin` | 관리자 | 주문 목록(이름, 상품, 금액, 상태, 날짜), 주차별 영상 링크 등록·수정 |
| `/terms`, `/refund`, `/privacy` | 법적 페이지 | `legal-pages.md` |

### 상품 데이터 (기본값)
```ts
{
  slug: "online-pt-4w",
  name: "온라인 PT 4주",
  price: 180000,
  weeks: 4,
  summary: "집에서 하루 20분, 원장님 피드백과 함께하는 4주 자세 관리",
}
```
- 상품은 `products` 테이블에 저장하고, 관리자 화면 대신 처음엔 Supabase에서 직접 넣는다.
- 16주 상품을 추가하려면 `products`에 한 줄 더 넣고 `program_weeks`에 16주치 영상을 등록하면 된다. 화면 코드는 그대로.

### 접근 규칙
- `/my`: 로그인 + 결제 완료(`orders.status = 'paid'`)한 상품만 보인다.
- `/admin`: 환경변수 `ADMIN_EMAILS`에 들어 있는 이메일로 로그인한 사람만.
- 유튜브 영상은 "일부 공개"로 올린다. 링크를 아는 사람은 볼 수 있으니 **완전한 보안이 아니라는 점**을 원장님께 한 줄로 알려준다.
