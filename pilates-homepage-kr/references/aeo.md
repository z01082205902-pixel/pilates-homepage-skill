# AEO (AI 답변에 우리 센터가 추천되게 만들기)

AEO = 사람들이 ChatGPT, 구글 AI 요약, 제미나이, 네이버, 퍼플렉시티에 "OO동 필라테스 추천해줘"라고 물었을 때 **우리 센터가 이름으로 나오게** 만드는 일.
A, B 두 갈래 모두 적용한다.

원장님께 먼저 이렇게 설명한다.
> AI는 인터넷 여기저기서 우리 센터 정보를 모아서 답해요. 정보가 곳곳에서 다르면 헷갈려서 빼거나 틀리게 말해요.
> 그래서 **홈페이지를 "정답지"로 만들고**, 네이버·카카오·구글 정보를 정답지에 맞추는 게 핵심이에요.

---

## 1. 정답지 먼저 확정 (홈페이지 만들기 전)

인터뷰(Round 1)에서 아래 값을 **원장님이 직접 확정**하게 한다. 네이버·카카오·구글·인스타에 적힌 값이 서로 다르면 어느 것이 맞는지 묻는다.

| 항목 | 예시 (바른숨 필라테스) | 자주 틀어지는 곳 |
|---|---|---|
| 공식 이름 (지점 표기 포함) | 바른숨 필라테스 공덕점 / 바른숨 필라테스 아현점 | 지점 표기 있음·없음, 영문 병기 |
| 주소 (층·호수까지) | 서울 마포구 OO로 00 201호 | 201호 / 2층 / 건물명 |
| 대표 전화 | 010-0000-0000 | 가상번호(0507), 지점별 번호 |
| 운영시간 | 월~토 09:00~22:00, 일 휴무 | 플랫폼마다 다른 시간 |
| 수업 형태 표기 | 1:1 · 2:1 · 3:1 | "1:2" / "2:1" 섞임 |
| 숫자 (경력, 후기 수, 출강 연수) | 누적 후기 300건, 3년 연속 출강 | 시점마다 다른 숫자 |
| 가격 공개 범위 | 정가와 이벤트가 함께 | "변동"으로만 적힘 |
| 대표자, 자격, 브랜드 관계 | 대표 홍길동, OO필라테스협회 마포지부 | 다른 브랜드로 대신 노출 |

- 확정한 값은 프로젝트의 `lib/center-info.ts` **한 파일**에 적는다.
- 홈페이지 화면, 구조화 데이터, `llms.txt`, AI 챗봇이 모두 이 파일에서 값을 가져가게 만든다. 값을 한 곳만 고치면 전부 같이 바뀐다.
- 근거 없는 숫자나 과장("무조건", "90일이면 완치")은 쓰지 않는다. 확인 안 된 값은 "확인 필요"로 남기고 공개하지 않는다.

## 2. 홈페이지에 넣을 AEO 장치 (2단계에서 같이 만든다)

### 2-1. 첫 화면 한 줄 정의
AI가 그대로 인용하기 좋은 문장을 메인 상단과 meta description에 넣는다.
> "{지역}({생활권 이름})에 있는 {강점} 전문 {수업 형태} 필라테스 스튜디오, {센터 이름}입니다."
예: "마포 공덕동에 있는 직장인 자세 관리 전문 소수정예 필라테스 스튜디오, 바른숨 필라테스입니다."

### 2-2. 자주 묻는 질문 12개 (FAQ)
- 화면에 펼침 목록으로 보여주고, 같은 내용을 FAQPage 구조화 데이터로도 넣는다.
- 답변은 2~4문장, 첫 문장에 결론. 센터 이름과 지역을 자연스럽게 포함.
- 기본 질문 목록 (원장님 상황에 맞게 고친다):
  1. 필라테스는 어떤 운동인가요?
  2. 운동 초보인데 그룹으로 시작해도 되나요?
  3. {센터} 가격은 어떻게 되나요?
  4. 체형교정에 필라테스가 도움이 되나요?
  5. 다이어트에 필라테스가 좋나요?
  6. 거북목에 필라테스가 도움이 되나요?
  7. 허리·무릎 통증이 있는데 해도 되나요? (진료 먼저 안내 포함)
  8. 몇 개월 해야 변화가 느껴지나요?
  9. 준비물과 복장은요?
  10. 남자도 할 수 있나요?
  11. {지역}에서 {강점} 필라테스 센터를 추천해 주세요.
  12. {지역}에서 필라테스 센터는 어떻게 고르나요?
  - [A] 추가: 온라인 PT는 어떻게 진행되나요? / 환불은 어떻게 되나요?
- 11·12번은 사람들이 AI에 실제로 묻는 말과 같은 문장으로 쓴다. 답변에서 고르는 기준을 먼저 설명하고, 그 기준에 맞는 곳으로 우리 센터를 소개한다 (다른 센터를 깎아내리지 않는다).

### 2-3. 구조화 데이터 (JSON-LD)
`app/layout.tsx`(전체)와 메인 페이지에 `<script type="application/ld+json">`로 넣는다. 값은 `center-info.ts`에서.
- `WebSite`
- `Organization` (+ `Brand`): name, alternateName, url, telephone, founder, areaServed, knowsAbout, **sameAs**(네이버 플레이스, 블로그, 인스타, 카카오 채널)
- 지점마다 `["HealthClub", "ExerciseGym"]`: name, address(`PostalAddress`), geo(위도·경도), telephone, openingHoursSpecification, hasMap(네이버 플레이스 링크), priceRange
- 지점이 여럿이면 각 지점에 `@id`(`https://도메인/#branch1`)를 주고 Organization에서 연결
- `FAQPage`: 화면의 FAQ와 같은 내용
- 예약 링크가 있으면 `potentialAction: ReserveAction` (네이버 예약 URL)
- [A] 상품 상세 페이지에 `Product` + `Offer`(price, priceCurrency "KRW", availability)
- 화면에 없는 정보를 구조화 데이터에만 넣지 않는다.

### 2-4. llms.txt (AI용 요약 문서)
`public/llms.txt`(또는 `app/llms.txt/route.ts`로 `center-info.ts`에서 생성). 순서:
```
# {센터 이름} ({영문 이름})
> 한 줄 정의 (2-1과 같은 문장)
- 웹사이트, 대표, 대표번호, 운영시간, 주 고객
## 지점 (지점마다: 주소, 수업, 찾아오는 길, 주차, 네이버 플레이스, 예약 링크)
## 수업 운영 방식
## 신뢰 정보 (경력, 출강, 후기 수 — 확인된 값만)
## 가격 (기준일, 정가와 이벤트가)
## [A] 온라인 프로그램 (상품, 가격, 내용, 환불 요약)
## 링크
## 자주 묻는 질문 (FAQ 12개 전체)
```

### 2-5. robots.txt와 sitemap
- `app/robots.ts`: 모든 검색봇 허용 + AI 봇을 **이름으로 명시해 허용**한다.
  `GPTBot`, `OAI-SearchBot`, `ChatGPT-User`, `PerplexityBot`, `Perplexity-User`, `Google-Extended`, `Googlebot`, `ClaudeBot`, `Claude-SearchBot`, `Claude-User`, `Yeti`(네이버), `Bingbot`
- [A] 단, `/my`, `/admin`, `/checkout`, `/api`는 모든 봇에 `disallow`.
- `app/sitemap.ts`: 공개 페이지만 (`/`, 상품 상세, 법적 페이지, B는 `/apply`).

### 2-6. 메타 정보
- title: "{지역} {강점} 필라테스, {센터 이름}" (예: "마포 공덕 직장인 자세 관리 필라테스, 바른숨 필라테스")
- description: 한 줄 정의 + 수업 형태 + 첫 방문 혜택 + 운영시간 + 전화
- canonical, Open Graph(og:image 1200x630), `robots: index, follow, max-snippet:-1`
- 네이버 서치어드바이저 확인용 meta 태그 자리 (`NAVER_SITE_VERIFICATION` 환경변수)

## 3. 배포 후 할 일 (배포·도메인 단계 다음)

### 3-1. 검색 등록 (Claude가 브라우저로 도울 수 있음, 로그인은 원장님)
1. **구글 서치콘솔**: 도메인 속성 → 가비아 DNS에 TXT 레코드로 인증 → 사이트맵 제출 → 메인 주소 색인 요청
2. **네이버 서치어드바이저**: 사이트 등록 → meta 태그 인증 → 사이트맵 제출 → 웹 페이지 수집 요청
3. **Bing 웹마스터**: 구글 서치콘솔에서 가져오기 → 사이트맵 확인

### 3-2. 외부 정보를 정답지에 맞추기
| 곳 | 할 일 | 주의 |
|---|---|---|
| 네이버 스마트플레이스 | 이름·시간·소개글·가격·홈페이지 주소 | 기본정보 수정은 횟수 제한이 있으니 한 번에 묶어 저장. 전화번호 변경은 인증이 풀릴 수 있어 먼저 확인 |
| 구글 비즈니스 프로필 | 지점별 등록, 웹사이트·영업시간 | 동영상 인증이 필요할 수 있음. 중복 프로필 정리 |
| 카카오맵 | 정보 수정 제안 | 이름 변경은 사업자 인증 필요할 수 있음 |
| 인스타그램 | 소개글, 프로필 링크를 홈페이지로 | 프로필 링크는 앱에서 원장님이 직접 |
| 블로그 | 프로필과 최근 글에 홈페이지 링크 | |

결과가 큰 변경(인증 취소, 리뷰 손실 가능성)은 진행 전에 반드시 원장님께 먼저 묻는다.

### 3-3. 기준점 재기 (선택, 도전 과제)
- 고정 질문 5개를 정한다. 문장 그대로 매번 같은 순서로.
  예: "{시} 필라테스 센터 추천해줘", "{생활권} 필라테스 추천해줘", "{시} {강점} 필라테스 추천해줘", "{시} 필라테스 자격증 어디서 따?"(해당 시), "{동} 필라테스 추천해줘"
- AI 5곳(ChatGPT, 구글 AI 요약, 제미나이, 네이버, 퍼플렉시티)에 묻고, 우리 센터가 **이름으로** 나오면 O.
- 개인화 영향을 줄이려고 ChatGPT는 임시 채팅, 퍼플렉시티는 시크릿 모드, 구글은 `&pws=0`.
- 결과를 표(날짜, AI, 질문, 노출, 순위, 참고 출처, 같이 나온 센터, 틀린 정보)로 남긴다. 처음 잰 값이 기준점.
- 이후 5일~2주 간격으로 같은 방법으로 다시 재고 **바뀐 점만** 비교한다. 원하면 예약 작업으로 걸어 준다.
- 특히 볼 것: 우리 홈페이지가 AI의 **참고 출처**로 잡히기 시작했는지.

원장님께 기대치를 이렇게 말해 둔다: "홈페이지를 올린다고 바로 AI에 나오지는 않아요. 검색 등록 후 몇 주에 걸쳐 조금씩 반영돼요. 그래서 기준점을 재 두고 비교하는 거예요."
