# 인터뷰

## 진행 규칙
- 한 메시지에 **한 라운드만** 묻는다.
- 답이 모호하면 보기를 2~3개 주고 고르게 한다.
- "알아서 해줘" / "그냥 따라할게요"라고 하면 **예시 답변**을 쓰고, 무엇을 골랐는지 한 줄로 알려준다.
- 각 라운드가 끝나면 1~2줄로 요약하고 다음 라운드로 간다.

---

## Round 0. 갈림길 (항상 첫 질문)

아래처럼 묻는다.

> 홈페이지를 두 가지 중 하나로 만들 수 있어요.
>
> **A. 결제형** — 온라인 PT 같은 상품을 홈페이지에서 바로 결제받아요. 구매한 분만 보는 운동 영상 페이지도 생겨요. (하루 정도, 실제 결제는 사업자등록과 토스 심사 필요)
>
> **B. 홍보형** — 센터를 소개하고 체험수업·상담 신청을 받아요. 결제는 지금처럼 센터에서 받아요. (2~3시간)
>
> 어느 쪽으로 만들까요? 처음이시면 B로 먼저 만들고, 나중에 결제를 붙이는 것도 가능해요.

**예시 답변(따라하기)**: 수업 1회차는 B, 2회차는 A.

---

## Round 1. 센터와 원장님 (공통)

1. 센터 이름 (없으면 가칭)
2. 위치(동네)와 오시는 길 안내 여부
3. 원장님 소개 한두 줄 (경력, 자격, 잘하는 분야)
4. 우리 센터 강점. 보기: 산전·산후 / 체형 밸런스 / 직장인 자세 관리 / 시니어 / 다이어트

5. 사람들이 우리 동네를 부르는 이름 (시·구, 동, 생활권. 예: 마포구 / 공덕 / 아현동)
6. 정답지 확정 (`aeo.md` 1장 표): 공식 이름(지점 표기), 주소(층·호수), 대표 전화, 운영시간, 수업 형태 표기, 공개할 숫자(경력·후기 수 등)
7. 이미 있는 온라인 채널 링크: 네이버 플레이스, 네이버 예약, 블로그, 인스타, 카카오톡 채널
   - Claude가 링크를 열어 볼 수 있으면, 플랫폼마다 다르게 적힌 값을 찾아 "어느 쪽이 맞나요?"라고 확인한다.

**예시 답변**: 바른숨 필라테스 / 서울 마포구, 오시는 길 포함 / 경력 10년, 국제 필라테스 지도자 자격, 직장인 자세 관리 전문 / 직장인 자세 관리 / 마포 · 공덕 · 아현동 / 바른숨 필라테스, 서울 마포구 OO로 00 2층, 010-0000-0000, 평일 07~22시·토 09~14시·일 휴무, 1:1·2:1·4:1, 경력 10년 / 링크 없음 (예시로 진행)

## Round 2-A. 온라인 PT 상품 (A 결제형)

5. 상품 이름과 가격 (기본: 온라인 PT 4주, 180,000원)
6. 구매자가 받는 것. 기본값:
   - 주 3회 따라하는 운동 영상 (유튜브 "일부 공개" 링크)
   - 시작 전 자세 설문 + 맞춤 루틴 안내
   - 주 1회 1:1 피드백 (카카오톡으로 자세 영상 보내면 코멘트)
   - 4주 후 변화 점검
7. 이런 분께 추천 / 이런 분께는 맞지 않아요 (각 2~3개)
8. 환불 규정. 보기:
   (a) 시작 전 전액 환불, 시작 후에는 남은 주차만큼 환불
   (b) 영상을 하나도 보지 않았다면 7일 안에 전액 환불
   (c) 직접 입력
9. 두 번째 상품도 넣을까요? (예: 16주 집중 PT) — 처음엔 하나만 추천

**예시 답변**: 온라인 PT 4주 180,000원 / 기본값 그대로 / 추천: 앉아서 일하는 직장인, 센터 방문이 어려운 분, 혼자 하면 작심삼일인 분 · 맞지 않음: 통증이 심해 진료가 먼저 필요한 분, 수술 직후인 분 / (a) / 하나만

## Round 2-B. 센터 수업과 신청 (B 홍보형)

5. 수업 종류와 대략의 가격 (예: 그룹 기구 필라테스, 1:1 개인 레슨, 듀엣)
6. 시간표를 넣을까요? (넣으면 요일·시간 알려주기 / 안 넣으면 "상담 시 안내")
7. 방문자가 남길 행동. 보기: 체험수업 신청서 / 카카오톡 채널 상담 / 네이버 예약 링크 (여러 개 가능)
8. 신청서에서 받을 정보 (기본: 이름, 연락처, 희망 요일·시간, 운동 목적, 개인정보 수집 동의)

**예시 답변**: 그룹 기구 필라테스 월 8회 22만원~, 1:1 개인 레슨 회당 7만원~ / 시간표 넣기 (평일 오전 10시·오후 7시·8시, 토 오전 10시) / 체험수업 신청서 + 카카오톡 채널 / 기본값

## Round 3. 화면과 마무리 (공통)

10. 디자인 톤 (`design.md`): 웜 베이지 / 클린 화이트 / 다크 프리미엄
11. [A만] 로그인: 구글 로그인 추천 (카카오 로그인은 심사에 며칠 걸려 나중에)
12. 추가 기능 (최대 2개 추천): 회원 후기 / 무료 맛보기 영상 / 카카오톡 채널 버튼 / 인스타그램 피드 링크
13. 가진 자료: 로고, 원장님 사진, 센터 사진, 영상 링크 (없으면 임시 이미지로 시작)
14. 하단 정보: 상호, 대표자, 연락처, 주소. [A만] 사업자등록번호, 통신판매업 신고번호도. 없으면 "예시 값"으로 채우고 나중에 바꾼다.

**예시 답변**: 웜 베이지 / 구글 / 회원 후기, 무료 맛보기 영상 / 아무것도 없음 / 예시 값
