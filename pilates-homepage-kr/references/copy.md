# 문구 가이드

## 기본 원칙
- 제목은 짧고 구체적으로 (15자 안팎)
- 번역투 금지: "당신의 삶을 변화시키세요" ✕ → "하루 20분이면 충분해요" ○
- 버튼은 동사로 끝낸다: "체험 신청하기", "4주 프로그램 시작하기", "카톡으로 물어보기"
- 원장님 말투로: 딱딱한 회사 말투보다 "~해요"체

## 흐름 (문제 → 공감 → 해결)
1. 문제: "하루 종일 앉아 있다 보면 목이 앞으로 나오고 어깨가 무거워지죠"
2. 공감: "운동을 해야 하는 건 아는데, 센터 갈 시간이 없어요"
3. 해결: "집에서 하루 20분, 원장님이 직접 자세를 봐 드려요"

## 금지 표현 (의료 효과처럼 보이는 말)
필라테스는 의료 행위가 아니다. 아래 표현은 과장 광고나 의료 오인으로 문제가 될 수 있으니 쓰지 않는다.

| 쓰지 않기 | 대신 쓰기 |
|---|---|
| 디스크 치료, 통증 치료 | 바른 자세 습관 만들기 |
| 체형 교정 보장, 척추 교정 완치 | 체형교정 전문 필라테스 (분야를 말하는 건 괜찮고, 결과를 보장하는 말이 문제) |
| 거북목 완치 | 목과 어깨가 편안해지는 움직임 |
| 100% 효과, 무조건 빠집니다 | 꾸준히 하신 분들이 많이 말씀하시는 변화 |
| 재활 치료 | 운동 재활 프로그램 (의료기관 연계가 없다면 "회복 운동") |
| 의사 추천 (근거 없이) | 쓰지 않음 |

- 후기를 쓸 때 **실제 회원 동의를 받은 후기만** 쓴다. 예시 후기는 "예시"라고 표시하거나, 실제 후기로 바꾸기 전까지는 섹션을 숨긴다.
- 전후 사진은 본인 동의 필수. 처음 만들 땐 넣지 않는다.
- 자주 묻는 질문에 "통증이 있으면 먼저 병원 진료를 받아보세요"를 넣는다.
- 변화 사례를 소개할 땐 "개인차가 있으며 의료 행위가 아닙니다"를 함께 적는다.
- "체형교정", "거북목" 같은 말은 사람들이 실제로 AI에 묻는 단어라 AEO에 중요하다. 분야·관심사로는 쓰되 결과를 약속하지 않는다.

## 예시 문구 (A 결제형, 온라인 PT 4주)
- 첫 화면 제목: "하루 20분,<br/>집에서 바르게"
- 부제: "바른숨 필라테스 원장이 4주 동안 직접 자세를 봐 드려요"
- 가격 카드: "온라인 PT 4주 · 180,000원 · 주 3회 영상 + 주 1회 1:1 피드백"

## 예시 문구 (B 홍보형)
- 첫 화면 제목: "마포에서 찾던<br/>소규모 기구 필라테스"
- 부제: "직장인 자세 관리 전문, 첫 수업은 체험으로 편하게"
- 버튼: "체험 수업 신청하기"
